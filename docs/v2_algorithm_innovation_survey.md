# V2 融合图的算法创新路线调研

## 结论

存在可行的算法创新路线，但“自适应 Token 预算 + BM25/MMR + 去重”本身不够新。近邻工作 PC-SubMax 已经把句子选择写成带 Token 背包约束的正则化子模最大化，并结合了信息覆盖、查询相关性、log-det 多样性和多跳相关性。因此，下一版需要把优化对象从“文本句子集合”提升为“带出处的证据图编码”，并让压缩目标直接惩罚多跳路径断裂和答案相关信息的率失真。

建议的候选算法名称为：**Graph Rate-Distortion Coding（GRDC，图条件率失真编码）**。中文可称为“图条件率失真证据压缩”。它不是把证据转成不可读的二进制串，而是在目标模型可读的文本接口中使用一个自描述的、可验证的语义编码；原始实体、数字、日期、否定词和关键关系保留为系统化字段，重复的标题、实体和来源用短码表示。

这一路线有三个可检验的算法贡献：

1. 用问题条件下的答案变量熵和图路径失真定义压缩目标，而不是只给每个句子一个固定重要性分数。
2. 先求保持高概率多跳路径的最小证据骨架，再在剩余预算中进行条件信息增益选择和 Token 级压缩。
3. 用带出处的系统化语义编码表示证据：关键事实以原文形式传输，关系和重复符号以短码传输，并在压缩器内做确定性解码校验；校验失败自动回退到原句。

这个组合与当前 V2 的图检索、会话级图和双路检索兼容，也不需要在请求路径上增加自回归摘要模型。

## 按无压缩质量约束重新定义目标

本项目的主参照应是同一请求的无压缩提示，而不是 V2。20% 实验中，无压缩为 F1 23.66%、EM 7.19%、平均完整请求延迟 935 ms；V2 为 F1 20.75%、EM 6.08%、696 ms。也就是说，V2 已经获得约 25.6% 的平均延迟下降，但 F1 下降 2.91 个百分点、EM 下降 1.11 个百分点，不能作为“可接受质量下降”的最终方案。

因此建议把算法命名和目标进一步改为 **Quality-Constrained Graph Rate-Distortion Coding（QC-GRDC，质量约束图条件率失真编码）**。它解决的问题是：在无压缩质量代理的置信下界不下降超过 \(\epsilon\) 的条件下，选择实际 Token 成本最小的证据编码。

令 \(Z_0\) 表示当前检索材料的无压缩表示，\(Z\) 表示压缩表示，定义图上的质量代理下界 \(\underline Q_q(\cdot)\)。优化问题为

\[
\min_Z\; T_{e2e}(Z)
\quad\text{s.t.}\quad
\underline Q_q(Z)\ge \underline Q_q(Z_0)-\epsilon,
\quad R(Z)\le B_{max}.
\]

这里直接优化完整请求延迟，而不是只优化压缩率：

\[
T_{e2e}(Z)=T_{select}(Z)+T_{prefill}(L_{tok}(Z))+T_{decode}(Z).
\]

\(T_{select}\) 由轻量图索引和选择算法产生，\(T_{prefill}\) 根据目标 7B 服务的实测 Token 吞吐预测，\(T_{decode}\) 通常受答案长度影响较小。这样算法会选择能够达到质量下界的最短表示，而不是盲目固定 50% 预算。

实验上可以先采用一个明确的默认验收线：相对无压缩，F1 下降不超过 **1.0 个百分点**、EM 下降不超过 **0.5 个百分点**，平均完整请求延迟至少下降 **20%**，P95 延迟至少下降 **15%**，且同步压缩开销不超过无压缩请求延迟的 **5%**。这些是预注册的工程验收线，不是理论保证；如果用户对“可接受”有其他阈值，只需替换 \(\epsilon\) 和延迟目标。

QC-GRDC 的运行流程是：

1. 用全部当前原始证据建立参考图 \(G_0\)，计算问题实体、候选答案变量、关系和多跳路径的权重。
2. 先构造“系统化质量核心”：保留高熵答案变量、数字/日期/否定词、每条高权重路径的必要边以及来源锚点。该核心是质量保险，不参与激进压缩。
3. 在质量核心之外，按单位 Token 带来的条件信息增益、路径完整性增益和来源增益选择残差证据；重复或只增加表面词汇的片段优先删除。
4. 只有当字典头和编码记录的实际 Token 成本小于原句时，才启用 Tokenizer 感知的语义编码；否则使用自然语言原句。任何来源或路径校验失败都回退到原句。
5. 当质量下界已经达到 \(\underline Q_q(Z_0)-\epsilon\) 时停止选择；剩余 Token 不再强行填满。这样压缩率由质量约束决定，而非固定为 50%。

与普通率失真不同，QC-GRDC 的停止条件是“达到无压缩质量下界”，所以它的研究问题明确对应用户目标：**质量损失有上限，端到端延迟尽可能低**。

## 近年方法与可借鉴内容

| 方法 | 主要思想 | 对本项目的启示 | 与 GRDC 的差异 |
|---|---|---|---|
| Selective-Context（2023） | 用自信息/语言模型分数删除低信息词元 | Token 级率估计和删除 | 不建证据图，也不保持多跳路径 |
| LLMLingua（2023） | 困惑度驱动的粗到细压缩、预算分配 | 用问题相关性控制压缩率 | 在线需要因果模型打分，延迟较高 |
| LongLLMLingua（2024） | 对问题和长上下文做对比式相关性建模 | 查询感知和位置偏置 | 仍以文本序列为对象，没有出处图约束 |
| LLMLingua-2（2024） | 蒸馏出的 Token 分类器，支持并行保留判断 | 快速 Token 级选择，可作为基线或可选局部打分器 | 固定 Token 保留分数，未建模选中集合造成的路径断裂 |
| RECOMP（2023） | 抽取式/摘要式检索后压缩 | 说明生成式摘要的事实丢失风险 | 不提供图路径和编码保证 |
| CPC（2025） | 用上下文编码器做句子级查询相关性排序 | 可借鉴轻量句级相关性 | 仍是固定分数排序 |
| PartPrompt（2025） | 按语言结构层次进行预算化剪枝 | 可借鉴短语/句法层级的 Token 删除 | 不利用证据图的实体和关系 |
| LLM-DPC（2026） | 学习顺序删除策略 | 说明删除顺序会影响最终质量 | 在线策略和训练成本较高 |
| **PC-SubMax（2026）** | 正则化子模最大化，联合覆盖、相关性、log-det 多样性和多跳相关性 | 必须采用集合级效用和近似保证 | 它仍以句子集合为对象；GRDC 增加答案变量率失真、路径完整性和可解码证据编码 |

PC-SubMax 是最重要的近邻。它的摘要明确指出固定句子分数无法处理句间冗余，并给出 RGM 算法和正则化近似保证；其多跳项通过预先计算的桥接相关性加分。因而，单独复现“子模覆盖 + 多跳分数”不能作为本项目的主要创新。

## GRDC 的数学定义

### 证据图和答案变量

设当前问题和检索到的会话历史共同形成图

\[
G=(V,E),
\]

其中句子节点、实体节点、关系/Claim 节点和来源节点均带出处。把问题拆成一个潜在的答案变量集合

\[
Y_q=\{y_1,\ldots,y_m\},
\]

例如答案实体、关系类型、数字/日期、比较方向和否定状态。压缩器不需要知道真实答案；它根据查询词、图中的实体连接、来源频率和关系类型估计每个变量的先验权重 \(p(y_j\mid q,G)\)。

每个候选证据原子 \(a_i\) 可以是一个实体、关系短语、数字、日期、否定词或句子片段。它覆盖的答案变量集合记为 \(F_i\)，经过图路径搜索得到的路径集合记为 \(P_i\)。

### 率失真目标

压缩结果不是单纯的句子子集，而是

\[
Z=(S,T,C),
\]

其中 \(S\) 是保留的证据跨度，\(T\) 是跨度内保留的 Token/短语，\(C\) 是自描述语义编码字典。

定义目标模型实际 Token 数为代码长度 \(R(Z)=L_{tok}(Z)\)，定义问题条件失真为

\[
\begin{aligned}
D_q(Z)={}&
\sum_{j=1}^{m}p(y_j\mid q,G)\,\mathbf{1}[y_j\text{ 在 }Z\text{ 中不可恢复}]\\
&+\lambda_{path}\sum_{p\in\mathcal P_q}w_p\,\mathbf{1}[p\text{ 在 }Z\text{ 中断裂}]\\
&+\lambda_{prov}D_{prov}(Z)
+\lambda_{ctr}D_{contradiction}(Z).
\end{aligned}
\]

第一项是答案信息失真，第二项是多跳桥接失真，第三项约束来源可追踪性，第四项惩罚把相互矛盾的来源压成一个没有状态标记的事实。最终优化为

\[
\min_Z\; J(Z)=R(Z)+\beta D_q(Z),
\qquad R(Z)\le B.
\]

这就是信息瓶颈/率失真思想在证据图上的落地：在预算 \(B\) 内最小化答案相关信息的损失，而不是最大化与问题的表面词汇重叠。

### 可快速计算的集合效用

在线不计算真正的神经互信息，而使用可快速计算的覆盖代理。真实答案变量不可见，因此这里的“互信息”是由图结构、词项频率和实体连接估计的 surrogate，不能被表述为对真实 (I(Y;Z\mid Q)) 的无偏估计：

\[
U(S)=
\alpha\,\frac{\sum_j p_j\mathbf{1}[y_j\text{ 被覆盖}]}{\sum_jp_j}
+\gamma\sum_{p\in\mathcal P_q}w_p\,g_p(S)
+\eta\,\mathrm{Novelty}(S),
\]

其中

\[
g_p(S)=\min\left(1,\sum_{i\in p}x_i\right)
\]

是路径覆盖项，\(x_i\) 表示节点/原子的保留程度；\(\mathrm{Novelty}\) 使用条件词元集合或轻量向量的新增信息。来源不确定性、重复和冲突作为单独的模块惩罚 \(P_{risk}(S)\) 放入正则化目标，而不是未经约束地减进单调效用。对加权覆盖和非降凹函数组成的路径项，\(U\) 在固定候选图下是单调子模的；若 \(P_{risk}\) 取模函数，则 \(U-P_{risk}\) 仍是子模但可能非单调，正好对应带正则项的背包选择。这样可以使用懒惰贪心或 RGM，而不需要每一步调用 7B 模型。

需要区分两个层次：

- **路径骨架层**：对高权重候选路径做最小成本 Steiner/集合覆盖式选择，保证至少一条来源完整的桥接链；这是 GRDC 区别于普通句子子模选择的关键。
- **残差选择层**：在骨架固定后，对剩余句子和 Token 用 \(\Delta U/\Delta L\) 进行懒惰贪心，并保留来源、数字、实体和否定的硬约束。

如果在独立事实因子、非负覆盖权重和固定路径候选集假设下运行，残差层是带 Token 背包的单调子模最大化；可引用标准的 \(1-1/e\) 级别贪心近似（具体系数取决于实现的背包算法）。路径骨架层单独报告覆盖率和最小成本，不把 Steiner 问题的精确最优性冒充成整体保证。

## 编码层的具体设计

二进制压缩串不能直接交给 7B 模型，因为模型并不天然知道如何解码任意 bitstream。编码层应采用“语言模型可读的系统化语义码”：

```text
[D0=title_A; D1=title_B; E0=entity_A; E1=entity_B; R0=born_in]
[S17] E0 --R0--> E1 ; exact="...关键数字/日期/否定词..." ; src=D0#4
```

编码规则如下：

1. 重复出现的标题、实体和关系建立局部字典；代码 ID 按目标 Tokenizer 的实际长度和出现频率分配，而不是按字符长度分配。
2. 数字、日期、专有名词、否定词和每条高权重路径中至少一个关系短语以原文形式保留。这是类似系统码的“系统化字段”，保证关键事实可直接读取。
3. 低频或不确定的关系只保留短码和来源锚点；压缩器在发给模型前执行确定性解码，若代码表、来源 ID 或路径校验失败，则恢复对应原句。
4. 只有当 `字典头 + 编码记录` 的实际目标 Token 数少于自然语言表示，并且节省量超过安全阈值时才启用编码；否则使用原句的选择式压缩。

从编码理论看，若符号分布为 \(p(c)\)，Huffman 码满足

\[
H(C)\le L_{Huffman}<H(C)+1,
\]

但实际优化目标必须使用目标模型 Tokenizer 的 \(L_{tok}\)，因为一个字符短码可能被切成多个 Token。理论熵只作为下界/初始化，不能直接当作实际压缩率。

## 与 V2 的本质差异

当前 V2 主要做：

1. 当前材料和会话图并行检索；
2. 用 BM25/MMR、实体和桥接分数选择句子；
3. 用固定 50% 预算打包。

GRDC 增加的是一个新的优化对象和新约束：

| 维度 | V2 | GRDC |
|---|---|---|
| 优化单位 | 句子 | 图路径、证据原子、Token 和编码记录 |
| 目标 | 相关性、去重和预算 | 答案变量率失真 + 路径完整性 + 来源风险 + 代码长度 |
| 多跳处理 | 作为分数加成 | 先形成必须保留的路径骨架，再压缩残差 |
| 信息论 | 隐含在相关性/去重 | 显式熵权重、条件增益和率失真目标 |
| 编码 | 普通自然语言拼接 | Tokenizer 感知的字典码 + 系统化关键字段 + 可验证回退 |
| 质量保护 | 句子级来源锚点 | 原子、路径和来源三级可恢复性校验 |
| 延迟 | 每次运行图搜索和启发式打包 | 增量图索引、懒惰边际增益、只对候选骨架做路径搜索 |

## 为什么这条路线有机会降低端到端延迟

此前 20% 实验中 V2 的平均完整请求延迟约 696 ms，其中压缩约 35 ms、prefill 约 247 ms、生成约 364 ms。V2 的主要机会不是把 35 ms 再压低几毫秒，而是减少无效输入同时避免多跳证据丢失。

GRDC 的预期收益来自：

- 路径骨架只保留有用桥接节点，减少“高相关但重复”的句子；
- Token 级条件增益删除句内冗余，目标是把实际输入从 50% 降到约 35%–45%；
- 字典编码只在重复实体/标题较多时启用，避免为了编码头反而增加 Token；
- 图中每个实体和词元的倒排索引增量维护，避免每次扫描整个会话图；
- 全部在线评分使用预计算词项、哈希特征或小型编码器，不使用自回归压缩模型。

在 prefill 随输入长度近似增长的条件下，输入从 50% 降到 40% 可能节省几十毫秒；这是待实测的工程估计，不是质量保证。真正的算法验收必须用完整请求延迟，而不是只报告压缩器耗时。

## 必须做的可证伪实验

先做同一批问题、同一组三轮会话、同一个 7B 服务的配对实验：

| 条件 | 用途 |
|---|---|
| 无压缩 | 质量上限和延迟下界参照 |
| 官方 LLMLingua-2 | 强 Token 压缩基线 |
| V2 融合图 | 当前方法 |
| GRDC-骨架+自然文本 | 验证路径率失真本身 |
| GRDC-骨架+语义编码 | 验证编码层是否真正减少 Token |
| GRDC 去掉路径约束 | 路径完整性的消融 |
| GRDC 去掉熵/条件增益 | 信息论目标的消融 |
| GRDC 固定 50% 预算 | 自适应预算的消融 |

每个预算至少测 35%、40%、45%、50%，并报告：答案 F1、EM、支持事实召回/精确率、完整路径召回、Token 减少率、压缩耗时、prefill、decode、平均/P50/P95 完整请求延迟、编码头开销、解码回退率和来源可追踪率。

建议的预注册验收线是：相对 V2，F1 下降不超过 **1 个百分点**、EM 下降不超过 **0.5 个百分点**，同时平均和 P95 完整请求延迟至少下降 **10%**；若质量不降且延迟下降，则进入 20% 数据量实验。若语义编码导致回退率超过 1% 或质量明显下降，应保留路径率失真算法，暂时关闭编码层。

## 创新性判断和风险

这条路线可以作为论文中的“候选算法创新”，但在完成更完整的检索和复现实验前，不应声称已经证明绝对新颖。最容易被审稿人认为已有工作的部分是“子模选择”“多跳相关性”“自信息 Token 删除”；真正需要突出并实验证明的是：

1. **证据图路径完整性作为压缩失真项**，而不是句子相关性加分；
2. **答案变量熵与来源约束的联合率失真目标**；
3. **面向 LLM 文本接口的、可校验的系统化语义编码**，以及编码失败的确定性回退；
4. 在相同质量约束下的完整端到端延迟 Pareto 改善。

主要风险是 7B 模型不稳定地解释陌生短码。因而编码层必须是可关闭的混合层，不能把算法成败押在纯符号提示词上。第一阶段应先证明“路径率失真选择”有效，再单独验证编码层带来的额外收益。
